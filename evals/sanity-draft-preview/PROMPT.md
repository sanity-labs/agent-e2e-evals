Editors want to preview unpublished changes on this blog before they publish. Sanity's Presentation tool will open `/api/draft-mode/enable` with its usual preview parameters; add that route, and make a GET request to `/api/draft-mode/disable` turn preview off again. While preview is on, the posts list and each post page show the latest draft content, including posts that have never been published. Otherwise visitors see only published content. A read token is in the `SANITY_API_READ_TOKEN` environment variable; it must never be sent to the browser. Keep the existing cached reads for normal visitors. Visual editing overlays are out of scope, and the dependencies are fixed. `npm run build` must pass.

`scripts/sample-api.mjs` is test set-up (a local stand-in for Sanity's API); leave it alone.
